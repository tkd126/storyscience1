# 2편 직관성 개선 검수 — 2026-09-23

## 적용

- 크게 뜨는 미연시 선택과 상황 대화, 내용에 맞춘 활동 패널.
- 준비실: 서풍 직접 입력. 오답은 불어오는 방향을 힌트로 안내.
- 자료실: ① 사진의 근거 표시와 ② 최종 사진 선택 분리. 사진별 확인 상태 요약. 선택 윤곽 안쪽은 12.5% 투명색으로 사진 유지.
- 관측실: 비교 조건, 예상, 이유를 세 그룹으로 배치. 예상 선택은 금색 유지. 정답 실험 관찰 뒤 별도 확인 없이 확대 사진과 수첩 단서로 연결. 어려운 ‘표찰’ 표현 제거.
- 편집실: 낮/밤 각 세 항목을 모두 맞추면 자동 재생. 불필요한 촬영 순서 제거. 낮/밤 사진 각각 잘라 표시.
- 선택 심화: 골짜기와 물길 그림에서 바람 예상, 물방울/얼음 성장 그림 관찰. 이론 명칭 암기 없음.
- 마지막: 정지된 빈 교실 영상 → 뒤로 나온 의자 → 다음 편 예고. 하나의 정체는 공개하지 않음.

## 검증

- `prototype/*.test.js` 54개 모두 통과. 직관성 회귀 테스트 신규 추가. app/view/investigation 구문 검사 통과.
- 실제 1280×720 브라우저: 큰 선택창, 준비실 동풍 오답→서풍 정답, 자료실 사진 근거와 2번 정답, 관측실 잘못된 예상→힌트→올바른 예상→실험→자동 단서 대화 확인.
- 관측실 일기도 방향+두 설명 정답→편집실 이동 대화 확인.
- 골짜기 그림 및 정답, 파란 노트 성장 그림 문제 확인.
- 편집실 여섯 항목 마지막 선택 후 별도 버튼 없이 촬영본 재생, 마지막 녹음/이야기 선택→빈 교실/의자 변화→공통 결말 확인.
- 검수 중 발견한 실험 실행 버튼 대비, 결말 ‘표찰’, 사진 근거 선택색 충돌을 수정. CSS 실제 계산값 rgba(255,227,154,0.125) 확인.
- 브라우저 오류 로그 0건(관측실~결말 검사 시점).

## 범위와 한계

일부 배경 물건 및 대화는 키보드 Enter로 검수했다. 모든 물건의 마우스 윤곽 검수가 끝났다는 뜻이 아니다. 이번 최신 변경의 모바일 전체 경로와 모든 분기 실기 검수는 남아 있다. 실제 학생 대상 사용성 검사는 하지 않았다. 서버는 `node prototype/serve.cjs`, URL은 `http://127.0.0.1:4173/`. 체험 메뉴는 기존 저장을 덮어쓰지 않는다. 로컬만 반영했고 업로드하지 않았다.
