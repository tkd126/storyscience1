# 2편 후속 검수 — 2026-09-22

## 확인 범위

- 실제 브라우저: 운동장 첫 장면부터 공통 결말 `내일, 창가의 빈자리` 도달. 기존 저장을 덮어쓰지 않는 구간 체험 사용.
- 운동장 이슬/안개 오답→정답, 구름, 카메라/관측 기록, 준비실 자동 이동.
- 준비실 문 열림 그림 교체, 천 방향 오답→정답, 긴 자로 메모 회수, 집게 고정, 기압 보관 약도 오답→정답, 테이프 삽입/되감기, 두 녹음 확인/순서 오답→정답, 자료실 진입.
- 자료실 1번 오답 후 2번 근거로 재시도. 사진 뒷면과 실내 사진을 거쳐 관측실 진입.
- 관측실 쪽지 펼치기, 공기 부피 맞추기→저울 해제→잘못된 표찰→수정, 테이프 기압 및 일기도 날씨 오답 재시도.
- 편집실 낮/밤 기록 확인 후 마지막 녹음과 공통 결말. 선택 활동 바람 방향, 물방울 병합, 얼음 알갱이 설명 재시도 확인.
- 1280×720에서 SVG 오브젝트 44개(운동장 10, 준비실 12, 자료실 9, 관측실 6, 편집실 7) 모두 실제 히트 가능한 점 존재 확인. 각 도형 내부 샘플 좌표의 elementFromPoint로 검사. 이는 모든 윤곽 픽셀이 미술적으로 완벽하다는 의미는 아님.
- 390×844에서 배경 좌우 이동, 질문 입력, 사진 가로 이동/표시/제출, 저울 조작과 정답 제출 확인. 844×390에서 저울 패널 내부 스크롤을 통해 끝까지 제출 확인. 화면 크기 강제 설정은 검수 후 해제.
- 브라우저 오류 로그 0건.

## 발견 및 수정

1. **사진 정답이 오답 흔적 때문에 막힘**: 다른 사진의 `clear` 표시까지 합쳐 검사하던 원인. 제출 사진에 표시한 근거만 검사하도록 변경. 다른 사진의 근거 둘을 합쳐 정답으로 처리하는 것도 차단. 회귀 테스트 실패→수정→통과, 새로고침한 브라우저에서 1번 표시를 남긴 채 2번 정답 통과 재검증.
2. **2편 대화 기록 누락**: 넘긴 대사를 최근 80개까지 기록하고 저장 상태에 포함. 실제 기록 창에서 태오/소미/은호 대사 표시 확인. 저장·복원·개수 제한 테스트 추가.
3. **좁은 화면 탐색 방법 불명확**: 탐색 중 좌우로 밀어 다른 물건을 살펴보라는 짧은 안내 추가. 별도 진행 버튼 추가 없음.
4. **모바일 녹음 패널 스타일 우선순위**: 작은 화면 여백/최대 높이 규칙이 데스크톱 선택자에 지던 문제 수정.

## 검증 해석과 남은 콘텐츠 범위

- Node 테스트 전체 50개 파일 통과. 자동 테스트는 상태 전이·선행조건·오답·저장 복원 등을 보완하며, 실제 브라우저 클릭 검수와 병행했다.
- 브라우저 연결이 두 차례 지연되어 재연결했지만 해당 대화에서 계속 진행 가능했다. 관측실 저울은 키보드 Enter로도 접근 검증했다.
- 녹음 조각은 `녹음 내용 · 자막`으로 제공한다. 실제 성우 음성, 3편 제작 및 그림 전체의 재제작은 이번 검수 완료 범위가 아니다.
- 모든 기종/모든 선택 순열의 무결점을 보증하는 검수는 아니다. 주요 진행 경로와 발견한 회귀를 위 범위에서 확인했다.
