# 2편 선택·학습 통합 변경 검수

2026-09-22. 구현 승인 요청에 따른 변경. 기존 사용자 작업/이미지 삭제 없음. 커밋·푸시는 하지 않음.

## 구현

- 이야기 선택 8곳, 선택값 저장, 의심/지지 선택에 따른 자료실 은호 반응.
- 준비실: 방향과 관찰 근거를 함께 선택, 원고 5문장 중 오류 찾기와 수정 이유. 마지막 녹음/반응 선택 이후에만 문 열림.
- 관측실: 쪽지 선행 조건, 이후 실험/일기도 순서 자유. 저울은 예측·이유 확인 전 결과 숨김. 일기도는 바람 방향+5설명 중 옳은 2개 조합. 양쪽 기록 완료 시 장소 이동 근거 대화 후 자동 이동.
- 편집실: 낮/밤 온도·기압·바람과 순서를 직접 연결. 이전 준비실 정답으로 건너뛰지 않음. 기존 해안 배경에 있는 낮/밤 사진을 SVG 뷰포트로 확대 재생하고 새 단서 대화에 연결.
- 활동 패널 내부 스크롤 유지, 이동한 장소에는 이전 스크롤을 넘기지 않음.
- 이전 version 3 저장 호환 revision 1. 완료 저장 유지, 진행 중 옛 테이프 문항은 원고 문항으로 전환.

## 실제 브라우저

- 준비실: 선생님께 설명 선택→천 이동 오답/수정→자 회수→집게 고정→원고 오류/잘못된 이유/수정→삽입/되감기→녹음→은호 지지→열린 문 이미지→자료실 선택지.
- 관측실: 쪽지 전 일기도 조사 차단→쪽지 펼침→일기도 우선 선택→잘못된 2개 설명 수정→실험에서 같은 무게라는 오답/힌트→올바른 예상/결과/표찰→편집실 자동 합류.
- 편집실: 온도·기압·바람 6항목 설정→거꾸로 재생 순서 오답→수정→낮/밤 서로 다른 사진과 자막 확인→마지막 녹음→은호에게 공유 선택→‘내일, 창가의 빈자리’ 결말.
- 검수 중 브라우저 오류 로그 없음.
- 기본 748×912 및 390×844 확인. 세로 편집창은 본문만 내부 스크롤, 제출 버튼 고정. 선택 변경 전후 내부 scrollTop 720→720. 임시 뷰포트 원복.
