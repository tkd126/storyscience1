# 2편 후반 구현 작업 지시

사용자가 승인한 v2 재구성 및 배포 요청의 구현 부분이다. 기존 미커밋 첫 만남/타이틀 변경을 보존한다. 프로젝트 지침의 세 문서를 먼저 읽는다.

## 구현 범위
- docs/chapter2-story-redesign-v2.md의 07~20 장면을 기존 정적 게임에 완성한다. 계획과 동일한 내용 아래 명시.
- 아침 교실에서 교사와 하나 도착 및 전날 약속 확인, 실내 대기 후 09:50 장비 준비, 10:08 바람, 10:20 경기, 10:24 기록 충돌, 10:40 비 중단, 11:20 두려움 고백, 11:35 단체 촬영, 18:00 사진관, 18:12 필름 도난, 18:14 공통 결말. 시각 역행 없음.
- 하나 살아 있음. 투명화/자기희생 단정 삭제. 두 위로 분기는 최소 2마디 후 합류.
- 은호는 사진관 가기 전에 목도리를 찾으러 보호자와 학교로 돌아감. 이후 사진관/도난 모든 장면에서 은호 그림과 대사 없음. 우비 목소리=은호 단정 삭제. 호루라기 닮음+부재만 의심. 교사가 추격 막고 신고. 정복 그림 미승인이라 이번 분기에서 화자로 추가하지 말고 기존 태오/소미 역할로 자연스럽게 치환.
- 모든 후반 탐색에 RoomScene.render를 실제 사용. 1편 가방 열기→아이템 선택→닫힘→그림 대상 클릭. 상시 행동 목록 제거. 사물별 조사와 작은 확대창, 닫기, 자유 재조사.
- 창고 열쇠는 교사 허락 후 지급. 열쇠→문, 열린 창고→집게봉/집게 획득, 풍향 깃발→지도 구역 예상 클릭→낮은 울타리 순서표에 집게봉→게시대 집게. 순서표 처음 고정했다가 사진 들다가 놓치는 인과.
- 테이프 보관함→테이프 획득→녹음기 삽입→재생 선행조건. 실제 녹음 문구는 은호의 3→4 전달+하나 응답, 태오 녹음 역할.
- 처마에서 천→젖은 상자 안→순서표/테이프 넣기→뚜껑 닫기→교사 이동. 예보/바닥 비교는 관찰, 암호 퀴즈 아님.
- 상태가 그림에 남도록 기존 열린 그림 사용/장치 상태 오버레이. 지형/장소 배경과 맞는 클릭 좌표. 타임어택 무제한 기본, 선택시 읽는동안멈춤, 실패로 자료 소실 없음.
- 사진 작업대는 사진·일지·녹음 연결 후 핵심 이유 한 개 글/구술로 완료 가능. 추가 개념/전이 세 문단은 별도 접힌 교사 활동. 기존 기록 기능 보존.
- 새 사진관 배경은 부모가 assets/photo-studio-cartoon-v1.png 제공 예정. app 배경 매핑 photoStudio 및 사진 활동 배경도 이것 사용. 교무실/강당 새 배경은 제공 못하면 기존 교실이라고 명확히 장소 대사 수정하여 거짓장소 피하기.
- 기존 활동 ID 및 저장 호환, chapter1 회귀 유지. 기존 중간 저장도 막힘 없이 보완 초기화. start preview 보호.
