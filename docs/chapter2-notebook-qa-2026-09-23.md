# 2편 수첩 이야기와 직관성 검수

## 변경

- 운동장 수첩 발견 → 준비실 녹음 뒤 사진 메모 → 관측실 창가 메모 → 영상 끝 목소리 메모 → 마지막 경고로 연결.
- 수첩은 단일 획득, 메모 중복 방지, 저장 복원, 탐색 중 다시 읽기 지원.
- 원고 오류 찾기와 설명 고치기를 분리. 첫 화면에서 두 번째 답을 미리 보여 주지 않음. 중간 이탈 시 완료한 첫 단계는 반복하지 않음.
- 사진 조건/질문 구분, 번호만 정답 판정. 벽 지도 자리에는 실제 사진 세 장 표시.
- 사진 뒷면의 장소 기록과 교사의 길 안내로 관측실 이동. 그림에 없는 저울을 사진에서 봤다고 하던 표현 제거.
- 공기 실험 고정 실행 영역, 선택 강조 유지. 영상 중앙 확대와 불필요한 빈 틀 축소.

## 실제 브라우저 확인

1280×720, 공개 장 선택 메뉴로 진입. 기존 저장을 덮어쓰지 않는 체험 사용.

- 준비실: 이야기 선택 → 서풍 입력 → 자/집게 사용 → 원고 첫 문제 오답 → 4번 정답 → 인물 대화 → 설명 문제. 창 닫기/재진입 시 설명 문제 유지 → 정답 후 테이프 획득.
- 자료실: 선택 → 일지/벽 사진 → 1번 오답 → 2번 정답. 추가 근거 클릭 없이 사진 뒷면으로 진행. 벽 액자에 비교 사진이 실제 보임.
- 자료실 → 관측실: 사진 뒷면/실내 사진을 조사하고 이동. 수첩 메모 누적 확인.
- 관측실: 쪽지/선택 → 공기 비교 → 일기도 → 편집실. 실험 실행 버튼 선택 전후 x258, y547.789, 너비240, 높이46으로 동일. 실험 결과 뒤 발견 대화 자동 진행.
- 편집실: 온도·기압·바람 여섯 답 선택 후 자동 재생. 중앙 확대 이미지 확인. 수첩의 네 메모 확인. 마지막 녹음/선택 뒤 결말 도달.
- 브라우저 오류 로그 0건.
