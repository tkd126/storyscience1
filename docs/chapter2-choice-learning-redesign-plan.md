# 2편 선택·추리·학습 통합 개편안

작성일: 2026-09-22 · 상태: 사용자 승인 후 주요 변경 구현·검수 완료

최종 승인 반영: 준비실 문은 **마지막 녹음에서 우리 이름을 듣고 반응을 고른 뒤** 열린다. 아래 초기안의 조기 문 개방은 채택하지 않았다. 관측실은 표찰과 일기도를 모두 확인한 뒤 보관란을 대조하여 자동 이동한다. 구현 범위·유지 항목과 검수 증거는 `chapter2-choice-redesign-qa.md`를 기준으로 한다.

## 1. 목표와 범위

현재 운동장→방송 준비실→자료실→관측실→편집실의 배경과 미연시 UI는 유지한다. 대화 선택, 단서의 선행 조건, 과학 활동, 이동 전 대화를 개편한다. 아래는 원래 설계안이며 실제 반영 내역은 위 최종 승인 사항과 검수 문서에 기록한다.

학생은 ‘과학 문제를 모두 푼다’가 아니라 ‘우리가 오기 전에 녹음된 우리 이름의 출처를 찾는다’는 목적으로 움직인다. 하나는 목소리·뒷모습·남긴 흔적으로만 등장하며 정체는 2편에서 확정하지 않는다. 기존 공통 결말인 ‘어제 사진 속 오늘의 수첩 / 내일 창가의 빈자리’로 합류한다.

권장 규모는 이야기 선택 8곳, 필수 학습 활동 7묶음, 선택 학습 활동 2묶음이다. 활동 하나에는 짧은 하위 조작이 포함된다. 목표 플레이 시간은 30~40분이며 실제 학생 플레이로 조정한다. 어려운 용어를 늘려 분량을 채우지 않는다.

## 2. 선택이 남기는 변화

### 이야기 선택

- 정답이나 점수는 없다. 즉시 2~4줄의 다른 반응, 조사 시작 순서 또는 동행 인물의 역할이 달라진다.
- 중요한 선택은 이후 장면에서 최소 한 번 다시 언급한다. 숫자로 된 호감도나 처벌은 표시하지 않는다.
- 예: 은호를 믿었다면 자료실에서 은호가 먼저 기억을 털어놓고, 원본 확인을 택했다면 은호가 기록을 들고 와 함께 대조한다. 어느 쪽도 나쁜 결말로 보내지 않는다.
- 다른 선택을 했다고 필수 정보나 학습 기회를 잃지 않는다. 짧은 분기 뒤 공통 단서에 합류한다.

### 추리·과학 선택

- 관찰 근거가 있어 정오를 판단할 수 있다. 틀리면 선택한 내용에 맞는 반례나 관찰 힌트를 준다.
- 정답 위치는 시도할 때마다 바뀌지 않는다. 오답 대사 이후 이미 입력한 예상과 표시는 유지해 고칠 수 있게 한다.
- 자유 서술은 단어 하나 포함됐다고 자동 정답 처리하지 않는다. 필수 진행은 명확한 선택·조합 또는 짧은 용어 답변으로 판정하고, 자유 설명은 기록 후 스스로 비교한다.

## 3. 장소별 이야기와 선택

### A. 운동장 — ‘아무도 없다는 것과 안 보인다는 것은 다르다’

목적: 하나의 목소리를 들은 뒤 마지막 촬영 흔적을 찾는다.

**선택 1 / 목소리에 어떻게 반응할까?**

1. 은호에게 ‘정말 하나 목소리였어?’라고 묻는다 → 확신하던 은호가 얼굴은 떠오르지 않는다고 말한다.
2. 소미와 목소리가 난 쪽을 함께 살핀다 → 안개 때문에 사람 유무를 판단하기 어렵다는 관찰로 시작한다.
3. ‘들렸다면 대답해 줘’라고 한 번 더 부른다 → 잠깐 정적, 스피커 잡음 뒤 소미가 혼자 들어가지는 말자고 한다.

셋 모두 벤치의 촬영 장비를 확인하는 데 합류한다. 안개 속으로 혼자 들어가는 선택은 만들지 않는다.

**선택 2 / 무엇을 먼저 비교할까?**

- 젖은 잎을 먼저 본다 / 골대 주변을 먼저 본다. 학습 순서는 달라도 모두 확인 가능하다.
- 같은 빛깔의 물방울 현상을 위치와 상태로 구분하고, 젖은 잎만으로 누군가 방금 다녀갔다고 단정할 수 없다는 결론을 얻는다.

이동 근거: 카메라 옆 촬영 메모에 ‘장비와 원본 테이프는 방송 준비실’이라고 명시한다. 대사로 목적을 확인한 뒤 선생님과 이동한다. 습기 자체로 사람의 행선지를 추정하지 않는다.

### B. 방송 준비실 — ‘날아간 종이와 고장 난 손잡이’

문이 바람에 닫히고 안쪽 손잡이가 헛돈다. 선생님은 바로 밖에 있어 응답한다. 위협적인 감금이나 비밀번호를 맞혀야 구조되는 상황은 아니다.

**선택 3 / 당황한 순간 무엇부터 할까?**

1. 선생님에게 손잡이 상태를 설명한다 → 선생님이 세게 당기지 말고 안내문을 봐 달라고 한다.
2. 은호와 연결문이 있는지 찾는다 → 평소 쓰던 동선과 관리 안내문 이야기가 나온다.
3. 소미와 바람에 날아간 종이를 찾는다 → 종이에 출입 안내가 있었다는 사실을 먼저 확인한다.

공통 행동: 천과 창문을 보고 종이가 이동한 쪽을 예상한다. 자/빗자루 중 손에 든 도구로 종이를 회수하고 집게로 고정한다. 종이는 실제 학교 관리 안내문이며 연결 출입구 위치와 고장 시 연락 방법을 담는다. 선생님과 연락해 문을 열거나 안내된 연결 동선을 확인한다. 문제 정답이 문을 직접 여는 장치가 되지 않는다. 문이 열렸다고 말하는 시점에는 배경도 열린 그림으로 바뀐다.

**선택 4 / 녹음에서 우리 이름이 들린다**

1. ‘은호야, 네가 장난친 건 아니지?’ → 은호가 서운해하지만 촬영 일지를 함께 확인하자고 한다.
2. ‘이름이 나오는 부분을 다시 확인하자.’ → 시간과 녹음 순서를 기록한다.
3. ‘네가 더 놀란 것 같은데. 괜찮아?’ → 은호가 하나와 녹음한 기억의 일부를 털어놓는다.

준비실은 종이 이동 추리와 녹음 케이스의 원고 오류 확인을 필수로 한다. 현재의 해풍/육풍 순서 맞추기는 편집실로 옮겨 반복하지 않는다.

이동 근거: 케이스의 촬영 날짜와 필름 번호가 있다. 선생님이 같은 번호의 촬영 일지와 사진이 자료실에 있다고 알려 준다. ‘누가 언제 녹음했는지 확인하기 위해’ 이동한다.

### C. 자료실 — ‘어제 사진에 오늘 물건이 있다’

**선택 5 / 은호가 자기 글씨가 아니라고 한다**

1. ‘믿어. 원본이랑 같이 비교하자.’ → 은호가 기억하는 촬영 상황을 먼저 듣는다.
2. ‘필름 번호부터 확인하면 되겠네.’ → 소미와 번호·날짜를 먼저 대조한다.
3. ‘고친 글씨, 다른 데서 본 적 있어?’ → 여백의 작은 표식을 먼저 찾는다. 필적만으로 범인을 확정하지 않는다.

촬영 일지와 약도를 확인한 뒤 사진 비교 활동을 연다. 잘못된 사진을 골라도 다른 사진의 근거를 계속 살필 수 있다. 정답 사진 뒷면에는 ‘관측실 원본 대조’라는 작업 메모가 있고, 사진에는 소미가 오늘 가져온 수첩이 보인다.

이동 근거: 사진만으로 날짜 오류인지 합성인지 알 수 없다. 관측실의 원본 관측 기록을 대조하러 간다. 매 이동마다 ‘얻은 사실→남은 의문→다음 장소에 있는 자료’를 대사 2~3개로 정리한다.

### D. 관측실 — ‘고쳐진 기록은 어디가 틀렸나’

들어오면 책상 쪽지를 발견하는 짧은 대화를 먼저 보여 준다. 쪽지에는 원본을 찾는 데 필요한 세 항목이 있다: 공기 비교 기록의 표찰, 당시 기압·날씨, 원본 보관 위치. 공기 무게와 방 이름을 임의로 일대일 암호화하는 대신, 실험 표찰 복원으로 같은 번호의 기록 묶음을 식별한다. 그 기록 묶음의 보관란에서 편집실을 확인한다.

선생님은 출입문 수리를 맡기러 잠시 나가며 아이들이 함께 기다릴 장소와 연결문을 명확히 안내한다. 아이들은 위험한 곳으로 몰래 이동하지 않는다.

**선택 6 / 쪽지를 함께 조사하는 방식**

- 은호와 실험 기록부터 / 소미와 일기도부터. 쪽지를 읽은 이후에는 두 조사 순서를 모두 허용한다.
- 실험이 끝나야만 일기도를 볼 수 있는 식의 불필요한 일렬 제한은 두지 않는다. 두 근거를 모두 찾으면 결론 대화로 합류한다.

저울은 결과를 숨긴 상태에서 조건 비교와 예측을 먼저 받는다. 일기도는 2지선다를 없애고 여러 근거를 함께 판단하게 한다.

이동 근거: 일치하는 관측 기록의 보관란에 ‘편집실, 해안 촬영 원본’이 나온다. 왜 그 기록을 골랐는지 아이들이 짚고 연결문으로 이동한다. 그림과 문 위치, 대사 방향을 일치시킨다.

### E. 편집실 — ‘우리가 직접 찾아낸 마지막 녹음’

이 방의 필수 행동을 자동 완료하지 않는다. 앞서 해풍을 맞혔다는 이유로 활동을 건너뛰지 않는다.

**선택 7 / 원본의 이상을 어떻게 확인할까?**

1. 영상의 시간부터 복원한다 → 낮·밤 장면 분류부터 시작.
2. 관측 메모부터 대조한다 → 온도와 바람 근거부터 시작.

둘 모두 같은 편집 보드에서 모든 근거를 연결해야 한다. 대사와 첫 강조 위치만 다르고 정답을 미리 주지 않는다.

필수 편집 보드: 낮 장면·밤 장면·나중에 덧붙은 음성 조각을 식별한다. 낮과 밤 장면에는 각각 온도 기록과 지표 부근 바람 화살표를 연결한다. 완성 후 ‘이 순서로 재생’을 누르면 복원한 순서대로 실제 화면과 자막이 바뀐다. 영상 시각과 맞지 않는 마지막 목소리가 드러난다. 초반 원고의 오류와 같은 표식을 발견해 자료들이 하나의 사건으로 묶인다.

**선택 8 / 마지막 메시지를 들은 뒤**

1. 선생님께 보여 줄 증거를 정리한다.
2. 은호에게 우리가 알아낸 사실을 먼저 말한다.
3. 소미와 내일 확인할 장소를 적는다.

마지막 대화와 남기는 기록이 달라진다. 앞서 은호를 의심/격려한 선택을 한 번 회수한다. 모든 분기는 ‘내일 창가의 빈자리’라는 공통 약속으로 합류한다. 하나의 얼굴·정체는 공개하지 않는다.

## 4. 문제 변경안 — 필수 7묶음

### Q1. 잎·안개·구름 관찰 연결 / 운동장

- 참고: 첨부 자료의 이슬·안개·구름 공통점과 생성 위치 문항.
- 변경: 용어를 따로 세 번 묻는 대신 관찰한 사진 세 장에 위치 설명을 연결한다. ‘물체 표면 / 땅 가까운 공기 / 높은 하늘’ 배치 후 공통 과정 ‘응결’을 짧게 입력한다.
- 관찰하지 않은 대상은 빈 카드로 남기고 해당 물건을 먼저 보도록 안내한다.
- 오답: ‘이건 잎에 붙어 있지 않고 골대 앞에 떠 있어.’처럼 위치 차이를 짚는다. 첫 오답부터 모든 정답을 나열하지 않는다.
- 이야기 보상: 젖었다는 이유만으로 최근 사람 흔적이라고 단정하지 않고 촬영 메모를 찾는다.

### Q2. 날아간 관리 안내문 / 준비실

- 변경: 찾을 장소만 2지선다로 고르는 대신 창문 위치·천 끝·가려진 부분을 확인한 뒤 예상 이동 경로를 고른다. 근거가 없는 구역은 오답 피드백에서 구분한다.
- 회수 도구는 자 또는 빗자루를 허용해 작은 행동 분기를 만든다. 도구가 필요한 상황을 먼저 보여 주고 선택하게 한다.
- 성공 후 관리 안내문이 실제로 펼쳐져 연결 출입구 정보가 보인다. 별도 과학 비밀번호는 없다.

### Q3. 누가 잘못 고친 촬영 원고 / 준비실

- 참고: `5-2_과학_2단원_7회_문제.hwp`의 이슬 실험 과정 오류 찾기, 단원평가 자료의 컵 겉면 응결 설명.
- 도입: ‘이슬을 찍은 영상인데 원고에는 따뜻한 컵이라고 돼 있어. 이대로라면 같은 장면이 나올까?’
- 1단계: 새로 작성한 다섯 문장 중 잘못된 한 문장을 선택한다. 부피·습도 등 불명확한 조건 때문에 복수 정답이 생기지 않도록 한 가지 오류만 넣는다.
- 2단계: 잘못된 ‘따뜻한’을 ‘차가운’으로 수정하거나 고쳐 쓴 문장을 선택한다. 단순 번호 선택으로 끝내지 않는다.
- 이야기 보상: 오류가 있는 줄만 잉크/필체가 다르고, 같은 수정 표시가 원본 케이스에도 있다. ‘학교 소개 영상의 과학 원고’로 설정해 시험지의 뜬금없는 등장을 줄인다.

### Q4. 어제 사진의 증거 선택 / 자료실

- 유지: 사진 3장과 촬영 일지·약도 비교.
- 보강: 사진 번호뿐 아니라 같은 사진의 안개 상태와 깃발 방향 두 근거를 표시해야 한다. 풍향은 불어오는 방향임을 약도와 함께 생각하게 한다.
- 일지·약도를 읽지 않은 상태에서는 문제를 열지 않는다. 먼저 눌러 놓은 다른 사진의 표시는 정답 판정에 섞지 않는다.
- 이야기 보상: 필름 번호 일치와 수첩 발견. 날씨가 같다는 사실만으로 사진의 날짜가 확정된다고 말하지 않는다.

### Q5. 공기 무게 예측→모형 실험 / 관측실

- 참고: 단원평가 1회의 공기 무게 비교, 2회의 측정값 예상.
- 기존 ‘기울어진 저울을 보고 낮은 쪽 선택’ 제거.
- 1단계 조건: 비교할 공기의 부피를 같게 맞춘다. 같은 기압에서 준비한 두 공기 시료, 용기 무게 제외라는 조건을 명시한다.
- 2단계 예측: 찬 공기가 더 무겁다 / 같다 / 따뜻한 공기가 더 무겁다 중 하나 선택.
- 3단계 근거: 네 설명 중 예측을 뒷받침하는 설명 선택. 예: 같은 부피에 들어 있는 공기의 양을 비교해야 한다. ‘찬 공기는 얼음이 들어 있어서’ 같은 오개념을 구분한다.
- 예측과 근거가 맞으면 ‘실험으로 확인’이 활성화되고 저울이 움직인다. 틀리면 조건을 짚는 힌트 뒤 수정 가능. 정답 여부에 따라 물리 결과 자체가 달라지지는 않는다.
- 4단계: 결과를 보고 기록 A/B에 맞는 온도 표찰을 붙인다. 결과 설명 후에만 해당 기록 묶음을 식별한다.
- 주의: 밀폐한 공기를 데우면 질량이 사라진다는 묘사, 차가운 용기 자체가 무겁다는 묘사는 금지. 모형임을 명시한다.

### Q6. 일기도와 고쳐진 날씨 원고 / 관측실

- 참고: 첨부 자료의 고·저기압 날씨, 바람 방향, 옳은 설명 두 개 고르기.
- 1단계: 두 지점의 기압값을 비교해 지표 부근 바람 화살표를 배치한다. 수평 기압차만 고려한 단순 모형이라는 조건을 표시한다.
- 2단계: 다섯 설명 중 해당 저기압 기록에 맞는 두 설명을 선택한다. 공기가 모여 상승, 구름·비가 생길 가능성 등 서로 다른 근거를 판단한다. ‘저기압이면 반드시 비’는 틀린 설명으로 구분한다.
- 3단계: 고기압 기록과 대조해 잘못 붙은 날씨 표찰을 바로잡는다.
- 이야기 보상: 쪽지의 표식·촬영 날짜·관측 내용이 일치하는 기록 묶음과 원본 보관 위치 확인. 정답 숫자로 자물쇠를 열지 않는다.

### Q7. 해안 촬영본 복원 / 편집실

- 참고: 모래·물의 가열, 해풍·육풍, 온도→기압→바람 방향 연결 문항.
- 기존 준비실 해풍/육풍 순서 문제 및 편집실의 단순 2지선다를 이곳으로 통합한다.
- 1단계: 밝은 장면과 어두운 장면에 맞는 낮/밤 표찰 배치.
- 2단계: 두 관측 기록을 배치. 낮에는 육지가 상대적으로 따뜻하고 밤에는 상대적으로 차갑다는 자료를 읽는다.
- 3단계: 각 장면에 기압 표찰과 바람 화살표를 연결한다. 낮 장면만 맞히고 넘어갈 수 없고 밤까지 비교해야 한다.
- 4단계: 낮→밤 재생 순서를 구성한다. ‘온도·기압·방향’의 모순만 단계별로 알려 주며 조합을 보존한다. 모든 답을 무작위로 다시 초기화하지 않는다.
- 5단계: 복원본 재생에서 마지막 음성 조각을 확인하고 원본과 불일치하는 부분을 표시한다. 기상 자료만으로 음성 위조를 확정하지 않으며, 화면 시각과 끊김 흔적을 함께 근거로 사용한다.
- 이야기 보상: 은호도 모르는 후반 녹음, 오늘의 수첩과 내일의 빈자리로 연결. 플레이어의 편집 결과가 재생 화면에 반드시 반영된다.

## 5. 선택 학습 2묶음

1. 자료실의 날씨 그래프: 기온·습도 자료에서 촬영 시각 후보를 비교하고 잘못된 설명을 고친다. 해당 그래프에서 읽을 수 있는 경향만 묻고 ‘항상 반비례’ 같은 일반화를 하지 않는다. 보상은 추가 촬영 대화/사진 설명이며 필수 결말을 잠그지 않는다.
2. 편집실 참고 장면 분류: 산비탈 낮 바람 방향, 작은 물방울 합쳐짐, 얼음 알갱이 성장 중 선택한 참고 장면을 올바른 설명과 묶는다. ‘곡풍·병합설·빙정설’ 암기는 요구하지 않는다. 이름은 활동 뒤 짧은 더 알아보기로만 제공한다.

## 6. 순서가 꼬이지 않는 탐색 규칙

물건을 무조건 순서대로 누르게 하는 것이 아니라, ‘맥락을 알아야 하는 행동’만 선행조건으로 제한한다.

| 물건 상태 | 클릭 반응 | 진행 상태 변화 |
|---|---|---|
| 맥락을 아직 모름 | ‘책상 쪽지부터 읽어 보자. 무엇을 찾는지 적혀 있을지도 몰라.’ | 문제/획득/완료 상태를 바꾸지 않음 |
| 지금 조사 가능 | 관찰 대화 또는 문제 시작 | 필요한 관찰만 기록 |
| 단서는 봤지만 필요한 근거 부족 | ‘일지는 찾았어. 이제 약도에서 동쪽을 확인해 보자.’ | 기존 답과 표시는 보존 |
| 이미 해결 | 알아낸 사실을 한두 줄로 회상 | 문제를 강제로 다시 풀게 하지 않음 |

- 첫 안내는 짧은 말풍선으로 보여 주되 다른 버튼을 가리지 않는다. 대화/문제 열린 동안 뒤 물건 클릭은 막는다.
- 순서 무관하게 살필 수 있는 장식·생활 물건에는 짧은 인물 대화를 제공한다. 모두 문제로 만들지 않는다.
- 허용된 조사 순서 A→B와 B→A 모두 같은 결론 대화로 합류한다.
- 이동은 필요한 단서와 결론 대화를 마친 뒤 자동 진행한다. ‘둘러보기/선생님 부르기/다음 방’ 같은 중복 진행 버튼은 추가하지 않는다.

## 7. 화면·피드백 원칙

- 이야기 선택은 기존 미연시 대화창 가까이에 2~3개만 표시한다. 선택 직후 화자 표정과 대사를 바꾼다.
- 과학 활동은 별도 작업면 안에 ‘현재 할 일’ 한 문장과 필요한 자료만 표시한다.
- 정답 제출/되돌리기/닫기 위치는 단계와 힌트 길이에 따라 움직이지 않는다.
- 드래그 조작을 넣어도 ‘조각 선택→놓을 자리 클릭’ 방식을 함께 제공해 터치와 키보드에서도 가능하게 한다.
- 정답 후 긴 해설 대신 ‘관찰한 결과 한 줄→그 결과로 얻은 단서→다음 행동’ 순서로 대화한다.
- 타이핑 효과, 노란 물체 윤곽, 이름표, 메뉴 등 1편 기반 UI를 유지한다. 선택 문구를 그림 안에 생성하지 않는다.

## 8. 구현 순서와 완료 기준

승인 후 다음 순서로 구현한다. 단순히 테스트가 통과했다고 몰입감까지 검증됐다고 표현하지 않는다.

1. 단서 선행조건 및 자유 조사 순서 정의, 잘못된 순서 접근 회귀 테스트 추가.
2. 이야기 선택 8곳과 합류 대화, 장소별 목적/이동 대사 구현. 선택의 후속 반응과 저장 복원 검증.
3. 저울 예측형 전환, 원고 오류 수정 및 5지 복수근거 활동 구현. 기존 정답 자동 완료/중복 문제 제거.
4. 편집실 배치·비교·순서 복원 및 재생 반영 구현. 앞선 정답 기록으로 건너뛰는 조건 제거.
5. 작은 화면과 마우스/터치/키보드 조작 검수. 필요한 원고·지도·편집 조각 시각 자료 보완.
6. 전체 Node 테스트와 실제 브라우저 정방향/역순/무작위 클릭/오답/중단 복원/두 조사 순서/모든 이야기 선택 합류 검수.

완료 기준: 쪽지보다 저울을 먼저 눌러도 줄거리가 앞서가지 않음, 예측 전 결과가 노출되지 않음, 다섯 보기에서 아무 두 개나 찍어 통과할 수 없음, 편집실에서 직접 조합하지 않으면 결말로 가지 않음, 모든 선택 분기가 막힘 없이 공통 결말로 합류함, 마지막 메시지가 학습 활동과 분리되지 않음.

## 9. 자료 이용과 확인해야 할 범위

첨부 HWP 12개의 텍스트에서 문항 유형을 참고했다. 그림/도표의 시각 정보와 원문 편집 상태는 아직 전부 확인하지 못했다. 원문 문항이나 정답표를 그대로 게임에 복제하지 않고 학습 개념과 유형을 바탕으로 새 문항을 작성한다. 모호한 단일정답, 조건 없는 기압·온도 일반화 등은 그대로 이식하지 않는다.

이 계획 승인 전에는 게임 코드, 기존 배경, 저장 데이터에 변경을 가하지 않는다.
