# 2편 재구성 계획서 v2 — 운동회에 없는 아이

상태: 사용자 ‘일단 만들어봐’ 승인으로 첫 탐색 구간 구현 시작(2026-09-17). 배포 변경 없음.
기준: 1편 결말과 기존 세계관을 유지한다. 기존 2026-09-15 운동장 설계의 충돌 항목을 순차 대체한다.

현재 구현 범위: 운동장 사물 조사·골대 뒤 첫 만남·이름 종이 사용·교무실 동행/기록 선택·다음 날 약속. 하나의 단발/겨울 외투 그림은 임시 시안이며 최종 확인 필요. 교무실 전용 배경, 후반 탐색/사진관/도난 동선은 아직 미구현이다.

## 1. 핵심 이야기

1편에서 찾아낸 촬영 약속을 따라 운동장으로 간 아이들은, 자리에 남은 물건을 조사하다 골대 뒤에 웅크린 하나를 발견한다. 하나는 은호가 자신을 알아보지 못하고 지나간 뒤 말을 걸 용기를 잃었다. 이름을 읽고 둘만 아는 촬영 실수를 이야기하자 은호의 기억이 잠시 돌아온다.

아이들은 이름과 녹음만으로는 기억을 오래 붙잡지 못한다는 것을 확인한다. 다음 날 예정된 학급 행사에서 하나의 모습과 함께한 일을 기록하기로 한다. 행사를 새로 여는 것이 아니라, 이미 예정된 학교생활 안에서 하나를 혼자 두지 않고 흔적을 남기는 것이다.

그러나 이어달리기가 끝나자 하나의 이름이 지워지고 은호는 자신이 마지막 주자였다고 기억한다. 플레이어는 직접 지킨 순서표, 바통 전달 녹음, 현상한 사진을 연결해 기억과 실제 사건의 차이를 확인한다. 마지막에 검은 우비가 원본 필름을 가져가지만 아이들이 나눠 보관한 사진과 수첩은 남는다.

## 2. 세계관·개연성 고정 규칙

- 하나는 살아 있는 학생이다. 육체가 투명해지는 것이 아니라 사람들의 기억과 기록에서 흔적이 흐려진다. 서로 다른 현상으로 섞어 쓰지 않는다.
- 이름과 목소리는 이미 있었던 기억을 잠깐 떠올리게 하는 단서다. 정답을 맞히면 하나가 돌아오는 마법은 없다.
- 처음에는 기록이 얼마나 도움이 되는지 인물들도 모른다. 관찰 → 작은 성공 → 다시 잊음 → 더 많은 기록이 필요하다는 판단 순서로 보여 준다.
- 가족이 하나를 계속 기억한다고 보장하지 않는다. 교사가 현재 보호자와 연락·인계를 확인하고, 재차 문제가 생기면 연락하도록 약속하는 장면을 둔다.
- 학생들은 귀가·의료·기상 안전을 책임지지 않는다. 교사가 보호와 연락을 맡고, 아이들은 곁에 있기와 기록 보존을 맡는다.
- 새천년맞이 학급 행사 안내는 12월 28일 교실에서 미리 보여 준다. 다음 날 갑자기 운동회가 생기지 않는다. 야외 경기는 짧고 날씨가 나빠지면 즉시 중단한다.
- 한 장소를 떠나는 이유, 도착한 장소, 경과 시간은 짧은 이동 장면과 날짜 표기로 연결한다.
- 은호와 검은 우비가 동시에 화면에 있지 않는다. 정체는 3편까지 확정하지 않지만 나중에 은호였다고 밝혀져도 성립하는 동선을 만든다.

## 4. 핵심 대사 초안

### 첫 만남: 찾아낸 뒤에 이름을 확인한다

태오: “골대 옆에서 기다린다며. 아무도 없는데?”
소미: “잠깐. 벤치 밑에 가방이 있어. 방송실에서 본 쪽지랑 같은 그림이야.”
플레이어가 골대 뒤를 조사한다.
하나: “……은호도 왔어?”
은호: “응. 그런데…… 미안, 우리가 아는 사이야?”
하나: “아까도 그렇게 물었어. 그래서 다시 부르기가 무서웠어.”
소미: “이 종이 좀 봐. 네가 잊지 않으려고 적은 이름이야.”
이름 종이를 은호에게 사용한다.
은호: “윤하나…….”
하나: “네가 ‘식용유’를 ‘식용우’라고 읽었잖아. 나 웃다가 촬영 다시 했고.”
은호: “……내가 소 흉내까지 냈지. 너 카메라 흔들린다고 그만하랬어.”
하나: “응. 그 얘기, 나 말고 기억하는 사람이 생겼네.”

### 다음 날까지 기다리는 이유와 긴장 유지

소미: “이름은 다시 떠올랐는데, 조금 지나면 또 헷갈려. 종이만 믿고 헤어져도 될까?”
선생님: “지금은 나와 교무실로 가자. 보호자께 연락하고 오늘 있었던 일을 함께 적어 두겠다.”
하나: “내일도 교실 앞에서 기다려 줄래? 내가 먼저 이름 말할게.”
은호: “내가 못 알아봐도 그냥 가지 마. 이 종이부터 보여 줘.”

### 기억이 바뀐 직후

은호: “마지막에 내가 들어왔잖아.”
하나: “네가 나한테 바통 줬어. 내 손에…… 아직 있는데.”
태오: “맞아. 내가 네 이름 부르면서 녹음했어.”
소미: “잠깐. 순서표도 달라졌어. 우리 기억으로만 말하지 말고, 아까 남긴 걸 확인하자.”

### 고백은 이유 없는 자기희생이 아니라 두려움에서 출발

하나: “미래 영상에서 내 자리가 비어 있었어. 아까 은호도 날 잊었고. 앞으로도 계속 이럴까 봐 무서워.”
선택 A: “잊으면 다시 알려 줘. 모른 척하고 지나가지는 않을게.”
선택 B: “아직 사진은 못 봤잖아. 지금 확인할 수 있는 걸 같이 보자.”
각 선택에 하나의 반응과 다른 친구의 약속을 붙인 뒤 촬영으로 합류한다.

## 5. 1편과 동일하게 할 조작 계약

외관만 닮게 하지 않고 입력 동작·화면 구조·피드백을 동일하게 한다.

| 기능 | 1편 기준으로 통일할 내용 | 현재 2편에서 없앨 것 |
|---|---|---|
| 기본 화면 | 장소 그림 + 상단 둘러보기 + 하단 가방 열기 + 인물 대화 | 활동별 전용 화면과 상시 소지품 버튼 나열 |
| 조사 | 그림 속 사물 자체 클릭, 사물별 짧은 대사, 필요한 경우만 확대 | ‘친구와 이야기/도구와 바람’ 메뉴를 먼저 열어야 하는 구조 |
| 가방 | 가방 열기 → 물건 설명 → 사용 선택 → 가방 닫힘 → 대상 클릭 | 일반 행동 목록의 ‘렌즈 닦기/상자 닦기/녹음기에 넣기’ 버튼 |
| 상태 변화 | 열린 문·빈 자리·삽입된 테이프·고정한 종이·닫힌 상자가 그림에 남음 | ‘열림 ✓’ 문구만으로 상태 대신하기 |
| 이동 | 그림 속 문·통로·장소 표식을 눌러 이동, 돌아와도 진행 유지 | 과제가 끝나면 새 활동으로 자동 교체 |
| 확대 창 | 누른 물건에 관련된 조작만 표시, 닫으면 원래 배경 | 여러 실험과 질문을 한꺼번에 나열한 큰 양식 |
| 발광 | 실제 사물 윤곽과 동일 좌표계, 그림 변경 시 윤곽도 변경 | 사각/타원 영역 전체 발광, 윤곽 없는 글자만 표시 |
| 실패 | 사물이 어떻게 반응했는지 두 인물의 짧은 대화 후 재조작 | 감점·15초 대기·정답 행동 목록 노출 |

방탈출 같은 재미는 ‘눈여겨본 물건을 다른 곳에 사용해 상황이 바뀐다’에서 만든다. 학생을 운동장에 가두거나 날씨 암호로 출구를 여는 설정은 넣지 않는다.

## 6. 탐색 공간과 연계 조작

- 운동장 전경: 벤치, 골대 뒤, 깃대, 트랙, 낮은 울타리, 방송석 입구, 창고 문. 한 장소에서 여러 사건을 겪으며 상태가 축적된다.
- 창고 확대: 열쇠로 문 열기. 집게·집게봉·천·상자를 개별 조사. 불필요한 공·운동화도 선택 조사할 수 있으나 전부 클릭할 필요는 없다.
- 방송석: 순서표 게시대, 녹음기, 테이프 보관함, 예보 메모, 덮개. 도구가 필요한 이유를 환경에서 볼 수 있다.
- 사진관 작업대: 사진 봉투, 사진 세 장, 관측 수첩, 녹음기. 밤 교실 그림으로 사진관을 대체하지 않는다.
- 하나·정복은 자기 대사 장면에서 실제 인물 그림이 필요하다. 다른 인물 그림을 화자로 강조하지 않는다. 새 외형은 제작 전에 사용자 검토를 받는다.

핵심 연결: 이름 종이→은호 / 열쇠→창고 / 천→렌즈 / 집게봉→울타리의 순서표 / 집게→게시대 / 테이프→녹음기 / 천→상자 안쪽 / 기록→마른 상자 / 사진·일지·녹음→증거 작업대.

## 7. 과학 활동과 최종 추리

### 안개 관찰
하나는 항상 가까운 일행 곁에 있다. 렌즈 표면을 닦은 결과와 먼 골대의 흐림을 비교한다. 풀잎 물방울이 이슬인지 비인지 외관만으로 확정하지 않는다. 전날 강수 기록과 교사의 아침 관찰을 보조 자료로 둔다. 이슬·안개·구름의 위치 비교는 관찰 뒤 짧게 정리하고, 생성 원인은 대조 활동이나 교사 질문으로 따로 확인한다.

### 순서표 회수
풍향은 불어오는 쪽, 깃발 끝은 불어가는 쪽임을 실제 그림에서 적용한다. 방향 객관식 대신 예상 구역을 지도에서 누른다. 종이 이동은 게임용 단순화임을 교사용 설명에 명시한다. 시간 도전은 선택이며 기본은 무제한. 읽는 동안 멈추고 시간 종료 뒤 친구가 종이를 붙잡아 진행을 보존한다.

### 비에 대비한 기록 보존
교사가 먼저 경기를 중단한다. 학생은 처마 아래에서 현재 바닥·바람·예보를 비교하고 이미 가진 기록을 보관한다. 포장은 실제 대상 선택으로 처리한다. 장소 판단과 재료 보관을 ‘정답 두 개 고르기’ 창으로 만들지 않는다.

### 사진 작업대: 한 결론에 여러 근거가 필요하게
사진 A: 준비 중인 주자, 동쪽으로 뻗은 깃발, 마른 바닥.
사진 B: 3번에서 4번으로 바통 전달, 남쪽으로 뻗은 깃발, 마른 바닥.
사진 C: 비어 있는 트랙, 남쪽으로 뻗은 깃발, 새 빗방울 자국.
일지: 10:00 서풍/마름, 10:20 북풍/마름, 10:40 북풍/첫 비. 세 장은 각 관측 시각에 한 장씩 촬영했다는 촬영 기록을 제공한다. 실제 날씨만으로 정확한 분을 추정할 수 있다는 오개념을 막는다.

플레이어는 B에 순서표의 3→4 구간과 바통 전달 녹음을 연결한다. 깃발·바닥으로 시각 봉투를 고르고, C가 같은 시각일 수 없는 이유를 설명한다. 하나가 4번이었다는 것은 경기 전 함께 확인한 순서표와 녹음의 이름을 교차 검증한다. 사진 속 이름표 하나로 정답이 드러나지 않는다.

긴 세 문단을 엔딩 조건으로 요구하지 않는다. 핵심 근거 연결 후 마지막 이유는 짧은 글 또는 구술로 제출한다. 추가 이슬/안개 생성 설명·새 날씨 상황 전이는 이야기 뒤 교사용 선택 활동으로 옮긴다. 게임 완료와 교사의 성취 판정은 분리한다. 공식 성취기준·사용 교과서 대조 전 단원 전체 평가라고 부르지 않는다.

## 8. 음향과 연출

- 일반 대사 넘김 무음. 조사/획득은 작은 종이·옷감 소리, 열쇠·걸쇠·테이프는 해당 조작 순간에만 소리.
- 평상시 낮은 잔잔한 BGM, 기억 충돌과 도난에서만 미스터리 BGM. 모든 문장에 긴장음을 반복하지 않는다.
- 테이프 잡음은 실제 재생 시작·정지 구간만. 종소리는 수업/행사 시각을 알리는 장면에만 쓴다.
- 새 음원은 사용·배포 권한 확인 후 포함. 음소거해도 사건·상태를 이해할 수 있게 표시한다.

## 9. 구현 순서와 승인 기준

1. 이 이야기안 검토: 하나 첫 만남, 다음 날 행사 동기, 은호 부재/도난 동선 승인. 아직 그림·코드 제작하지 않음.
2. 대사 전체 집필: 모든 분기를 포함해 읽어 보고 ‘누가/어디서/무엇을 알고 말하는가’ 점검. 장소·화자·기록 내용 대조표 작성.
3. 1편 공통 조작 규격 추출: room.js의 화면·가방·확대·사용 동작을 재사용하거나 동일한 공통 뷰로 분리. 클래스 이름만 같게 붙이는 방식 금지. 1편 회귀 테스트 선행.
4. 운동장 첫 탐색만 세로 절편 제작: 빈 골대 → 물건 조사 → 하나 발견 → 이름 종이 사용. 사용자 확인 전 다섯 활동을 한꺼번에 확장하지 않음.
5. 승인된 틀로 창고·회수·방송석·포장 확장. 상태별 그림과 윤곽을 함께 검증.
6. 사진관 작업대와 결말 구현. 교사 기록은 별도 접힌 화면으로 보존.
7. 기존 저장 이관, 테스트, 실제 브라우저 연속 플레이 후 별도 배포 요청에 따라 반영.
