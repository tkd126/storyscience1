# 2편 추가 기능 검수 · 2026-09-22

범위: 새 조작 실험 3종, 사진 근거 선택, 구간 선택, 편집실 방향 문제와 결말. 로컬 4173. 전체 이야기 최초 장면부터의 연속 완주는 이번 검수 범위가 아님.

## 실제 브라우저 확인

- 390×844: 저울 부피 불일치 제출 → 힌트, 같은 부피에서 잘못된 표찰 → 힌트, 찬 공기 표찰 → 성공 대화.
- 390×844: 해안 낮 모형 오답 → 수정, 밤 모형 완성 → 성공 대화.
- 390×844: 기압 1016/1016 정지, 왼쪽 1012 역방향, 1020 정방향 1.5초 회전, 1024 정방향 0.65초 회전. 오답 후 정답 대화.
- 390×844: 자료실 일지+약도 → 사진 자동 표시. 두 번째 사진의 골대/깃발 직접 선택, 첫 사진 오답 → 두 번째 정답 → 후속 탐색.
- 1366×768: 편집실 구간 진입, 산비탈 바람 방향 오답/정답, 해풍·육풍 확인, 녹음 후 「내일, 창가의 빈자리」 결말.
- 검사 후 콘솔 error 로그 0건.

## 발견하고 수정한 사항

1. 모바일 사진을 세 장 동시에 축소해 깃발 터치 영역이 너무 작음. 900px 비교판을 좌우 스크롤하도록 수정. 깃발 영역 약45px 이상 유지.
2. 사진 클릭마다 스크롤이 초기화됨. 다시 그린 뒤 사진/실험/장면 스크롤 위치 복원. 수정 후 두 번째 사진 선택 뒤 scrollLeft=228 유지 확인.
3. 같은 종류의 근거가 여러 사진에 동시에 선택 표시됨. 사진별 표시를 따로 저장하고 근거만 합산. 수정 후 선택 표시가 '2번 골대 뒤', '2번 깃발' 두 개뿐임을 확인. 회귀 검사 추가.
4. 투명 사진 영역에 공통 버튼 그림자가 남음. 그림자/여백 제거.

## 자동 검사와 제한

- Node 테스트 파일 45개 통과. 변경 JS 구문 검사 통과.
- 실제 휴대전화 하드웨어가 아닌 브라우저 viewport 검사임.
- 본편 저장을 보호하기 위해 구간 체험을 사용. 실제 저장 덮어쓰기/새로고침 복원은 이번 브라우저 검수에서 하지 않음.
- 기존 전체 배경의 모든 물건 윤곽, 전체 이야기 연속 완주, 실제 학생 난이도 검증을 완료했다고 주장하지 않음.
- 커밋/업로드/배포하지 않음.
