# 교사 관점 점검 · 2026-09-16

## 판단

현재는 수업용 시범 플레이 단계다. 재미를 확보했다고 단정할 학생 관찰 자료가 없다. 1편 회귀 테스트와 2편 사건·평가 경로를 검토했으며, 두 편 모든 대사를 실시간 연속 플레이한 검증은 아니다.

## 최종 과제의 평가 범위

1. 사진 A/B/C의 풍향과 촬영 시각을 직접 기록한다. 모든 기록이 서로 맞아야 한다. 방향 오류와 자료 교차 오류의 피드백을 구별한다.
2. B와 C는 같은 풍향이므로 풍향만으로 시각을 정하지 못한다. 바닥 변화와 함께 다른 시각을 배제하는 설명을 받는다.
3. 렌즈를 닦아도 흐릴 때 풀잎 표면/지면 가까운 공기/높은 하늘의 물방울을 구별하게 한다.
4. 새 날씨 상황에서 촬영 장소와 기록 보관 방법을 두 근거로 제안하게 한다.

최초 대조 성공 여부·대조 횟수·학생 서술 세 가지를 본편 진행에 보관한다. 체험 모드는 본편 저장을 덮어쓰지 않는다. 서술 제출은 성취 판정과 다르며 단순 키워드/글자 수 자동 채점을 하지 않는다. 학생의 실제 설명을 교사가 확인해야 한다.

### 교사용 관찰 기준

| 기준 | 충분 | 보완 필요 |
|---|---|---|
| 풍향 | 불어온 쪽과 깃발 끝의 관계를 설명하고 적용 | 끝이 향한 쪽을 풍향으로 씀 |
| 복합 자료 | 깃발+바닥을 함께 사용하고 다른 시각을 배제 | 한 자료나 답 시각만 제시 |
| 물방울 위치 | 표면의 이슬/공기 속 안개/높은 구름 구별 | 물방울 위치나 렌즈 흐림 혼동 |
| 생활 적용 | 현재 관측/예보와 안전한 행동·보관 방법 연결 | 아침 기록만 사용하거나 근거 없는 선택 |

## 아직 남은 위험

- 관찰 스케치는 간단한 기호와 글로 표시된다. 사진 속 행동·물방울을 직접 확대 관찰하는 삽화는 더 필요하다.
- 보관함 암호는 세계관에서 설명했지만 과학 학습을 위한 장치라는 인상이 남을 수 있다. 학생이 자연스럽게 받아들이는지 관찰 필요.
- 날아가는 종이의 실제 이동 연출과 긴장감은 부족하다. 시간 도전은 현재 선택형이며 읽는 동안 정지한다. 속도를 과학 성취 점수로 사용하지 않는다.
- 최종 설명 항목은 평가를 보강하지만 입력 부담이 커질 수 있다. 모둠당 구술 후 한 학생 입력 또는 교사 기록을 허용하는 수업 운영 권장. 현재 구술 녹음/교사 채점 UI는 없음.
- 단원 전체 성취기준 충족을 주장하지 않는다. 사용 교과서와 공식 성취기준 대조, 초등 5학년 실사용 시간·난이도·흥미 검증이 남는다.
- 다음 학생 시범 플레이에서 무힌트 진행 막힘, 오답 수정 이유, 다른 시각을 배제하는 설명, 완료 시간과 읽기 부담을 기록한다.

## 실행

서버가 꺼졌으면 `node prototype/serve.cjs`. 서버 없이 `prototype/index.html`을 직접 열어도 실행된다. HTTP와 파일 실행의 저장 공간은 별개일 수 있으니 이어하기는 같은 방식으로 실행한다. Start-Game.ps1은 Node가 없으면 파일 실행으로 대체하며 자동 시작 서비스는 설치하지 않는다.
