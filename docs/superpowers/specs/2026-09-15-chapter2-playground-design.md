# 2편 재구성: 운동회에 없는 아이

상태: 사용자 승인 방향을 구체화한 설계, 구현 전 검토용.
대상: 초등학교 5학년, 정적 웹게임의 기존 2편 교체. 기존 1편 보존.

## 1. 이번 개편의 기준

운동장을 그림 배경이 아니라 직접 조사하고 도구를 사용하는 공간으로 만든다.
중심 사건은 ‘하나가 마지막 주자였다는 증거를 찾아 지킨다’이다.
과학 문제를 풀 때마다 문이 열리는 연속 퀴즈방으로 만들지 않는다.
장소 탐색 → 인물 반응 → 물건 조작 → 관찰 결과 → 다음 사건 순서로 진행한다.
선택 분기는 최소 두 사람의 말 또는 같은 인물의 두 대화를 거쳐 합류한다.

추천한 혼합형을 적용한다. 자유 탐색에는 시간제한이 없고, 짧은 조작 두 곳에만 선택 가능한 타임어택을 둔다.
숫자 자물쇠 연속 풀이와 전체 플레이 시간제한은 채택하지 않는다.

## 2. 운동장 공간과 화면

운동장 전경 1장과 준비물 창고·방송석 확대 장면을 연결한다.
전경에는 골대, 깃대, 트랙, 동쪽 생울타리, 처마 아래 방송석, 백엽상, 창고 문, 배수로를 배치한다.
카툰풍·겨울 학교·흐린 오전 분위기를 유지하며 이미지 자체에는 문자를 넣지 않는다.
안개·맑아짐·구름 증가·비는 같은 공간의 상태 변화로 보여 준다. 안개를 플레이어가 없애는 장치는 없다.

하단에는 1편 방식의 인물 대화와 가방을 둔다. 넓은 문제 창으로 전경을 계속 덮지 않는다.
작은 확대 조사 창에서 기구·물방울·사진을 보고, 닫으면 원래 장소와 조사 상태가 유지된다.
활성 물건은 사물 윤곽만 빛난다. 불규칙 물건을 큰 사각형 테두리로 강조하지 않는다.
열린 창고·꺼낸 물건·고정한 순서표·닫힌 방수함을 실제 화면 상태에 반영한다.
모바일은 그림 전체를 축소하고 확대 조사 시 조작 공간을 제공한다. 클릭 대신 터치도 가능하다.
키보드는 초점 표시와 사물 목록으로 동일 기능에 접근한다. 드래그 조작에는 ‘선택 → 대상 누르기’ 대안을 둔다.

## 3. 진행 구성

### A. 전날: 하나 발견

기존 12월 28일 장면과 이름·목소리로 잠시 기억이 돌아오는 장면을 보존한다.
교사가 보호자에게 연락한 뒤 하나는 귀가한다. 다음 날 기념 촬영에서 얼굴도 남기기로 약속한다.

### B. 안개 낀 아침: 사라진 것이 아니라 가려진 것

하나가 멀리 있는 골대 근처에서 손을 흔든다. 은호는 또 사라진 줄 알고 겁을 낸다.
교사 곁 안전 구역에서 렌즈, 가까운 풀잎, 먼 골대를 확대 조사한다.
렌즈 닦는 천을 사용해도 먼 골대는 흐릿하다. 가까운 풀잎에는 붙은 물방울이 보이고 공중에는 작은 물방울이 떠 있다.
‘렌즈를 계속 닦기’는 관찰 결과가 바뀌지 않는 재시도 반응이지 감점이 아니다.
관찰을 모은 뒤 ‘안개가 걷힐 때까지 가까이 모여 기다리자’를 친구에게 제안한다.
소미가 이슬·안개·구름을 결과에 맞춰 짧게 정리한다. 용어 세 개를 먼저 맞혀야 진행하는 기존 양식은 제거한다.
선택 조사: 백엽상 기온 기록, 높은 구름, 젖지 않은 처마 밑 바닥. 중요한 기록은 수첩에 관찰 내용만 남기며 정답 행동 목록은 쓰지 않는다.

### C. 준비물 창고: 처음으로 도구를 직접 사용

교사가 사용할 물건을 허락하며 창고 열쇠를 준다. 가방에서 열쇠를 선택해 창고 자물쇠에 사용한다.
문이 열린 그림으로 전환한다. 열쇠는 야외 출입이나 선생님께 돌아가는 조건이 아니다.
집게, 얕은 곳의 물건을 집는 집게봉, 마른 천, 투명 방수함을 직접 살펴보고 가져온다.
공, 응원 깃발, 오래된 운동화 등 선택 조사 물건에도 인물 반응을 넣는다. 모든 장식 조사를 필수 조건으로 삼지 않는다.
집게봉은 배수로 내부나 위험한 높은 곳에 사용하는 도구가 아니다. 손이 닿기 어려운 낮은 울타리 바깥의 종이만 집는다.

### D. 날아간 순서표: 풍향 추적 타임어택

사진에 담으려고 집게를 푼 순간 순서표가 날아간다. 마지막 주자의 이름이 남은 유일한 종이다.
첫 연습은 무제한. 깃발 끝과 출발점을 보고 다음에 종이가 걸릴 구역을 누른다.
풍향은 ‘불어오는 쪽’으로 표현하고, 깃발은 ‘불어가는 쪽’으로 뻗는다. 동서남북 표시는 게임 UI가 담당한다.
본 조작은 35초, 세 구간이다. 각 구간 시작에 새 깃발 상태를 보여 주며, 바람은 판단 도중 무작위로 바뀌지 않는다.
잘못 고르면 종이는 그 구역에 없고, 실제 이동을 관찰한 뒤 같은 구간에서 다시 판단한다. 정답 구역은 글로 선공개하지 않는다.
최종 도착은 낮은 생울타리. 집게봉으로 회수한 뒤 집게로 순서표를 고정한다. 회수와 재고정을 모두 화면에 보여 준다.
시간이 끝나면 은호가 종이를 막아 세운다. 마지막 구간부터 재도전하거나 무제한으로 전환한다. 증거 소실·게임오버는 없다.
기압 비교는 별도 관측 모형에서 공기 이동 화살표를 배치하는 보조 단서다. 실제 종이 경로를 기압 숫자만으로 확정하지 않고 현장의 깃발로 검증한다.
성공 반응 예: ‘태오: 잡았다! 끝이 조금 접혔네.’ → ‘하나: 괜찮아. 내 이름, 아직 읽을 수 있어.’

### E. 경기와 기억의 어긋남

교사가 시야·바닥을 확인한 뒤 짧은 경기를 허락한다. 경기 자체는 짧은 바통 전달 연출로 두며 별도 과학 없는 클릭 연타 게임은 추가하지 않는다.
하나에게 바통이 넘어가고 결승선에 도착한다. 이후 은호는 자신이 마지막 주자였다고 기억한다.
플레이어가 지켰던 순서표는 이름이 흐려졌지만 주자 번호·달린 순서는 남아 있다.
방송석 녹음에는 태오가 하나를 부르는 목소리가 남는다. 사진도 확보해야 할 이유가 여기서 생긴다.

### F. 날씨 급변: 관측과 기록 보호 타임어택

교사가 먼저 야외 경기를 멈춘다. 학생에게 위험한 날씨 속 구조 임무를 맡기지 않는다.
처마 아래 방송석에서 오전 기록·새 예보·현재 빗방울과 바람을 비교한다. 자료는 사물 조사로 모으며 처음부터 한 문제 창에 모두 나열하지 않는다.
새 예보만으로 ‘저기압이면 반드시 비’라고 결론 내리지 않는다. 현재 관측과 미끄러운 바닥도 근거로 사용한다.
플레이어는 실내 이동을 제안하고, 교사가 확정한다. 다음으로 방송석의 기록을 챙기는 45초 조작을 선택할 수 있다.
사진용 기록지·녹음테이프를 골라 방수함에 옮기고, 가장자리에 물기가 있는 함은 천으로 닦은 뒤 뚜껑과 잠금 걸쇠를 닫는다.
축구공·젖은 응원 깃발을 함께 넣으면 기록을 보호하는 목적에 맞지 않는다는 관찰 반응이 나온다. 방수함 내부를 젖게 하는 선택은 되돌릴 수 있다.
이는 날씨가 생활과 준비에 미치는 영향을 적용하는 짧은 조작이다. 타이머 숫자나 제한된 가방 칸을 과학 개념처럼 채점하지 않는다.
기한 종료 시 소미가 덮개를 잡아 준다. 완료한 포장은 유지하고 나머지를 재시도한다. 교사는 외부 기구를 회수한다.

### G. 실내 촬영 → 저녁 인화 → 심화 추리

실내에서 하나의 고백과 선택별 두 마디 반응, 단체 촬영을 진행한다.
1999년 필름 카메라 사진은 찍자마자 확인할 수 없다. 기존 ‘촬영 직후 경기 사진을 보며 시간 추리’는 삭제한다.
저녁, 교사와 사진관에서 인화 사진을 받은 뒤 세 장 중 ‘하나가 마지막 주자로 달린 사진’을 찾는다.
사진에는 얼굴이 일부 가려져 있으므로 풍향, 주자 위치, 동시 녹음, 관측 시각을 함께 연결해야 한다.
작업대에 사진·관측표·녹음 조각을 배치한다. 사진 선택만이 아니라 서로 맞는 근거 두 개를 붙이고 촬영 시각을 입력해야 완료한다.
기본 후보: 10:00 서풍·비 없음 / 10:20 북풍·비 없음 / 10:40 북풍·비 시작. 마른 종이 하나만으로 비 여부를 확정하지 않고 같은 순간 녹음으로 교차 확인한다.
단순히 ‘하나가 마지막이었다’고 직접 말하는 녹음을 정답 단서로 쓰지 않는다. ‘세 번째가 바통을 넘겼다’, ‘아직 비는 안 온다’ 등 결합이 필요한 정보를 준다.
심화는 시간제한 없음. 틀리면 충돌하는 자료만 짚고 재배치한다. 힌트는 관찰 위치 → 비교 기준 → 일부 연결 순으로 제공한다.
이후 인화 사진·수첩을 나눠 갖고, 검은 우비가 필름을 가져간다. 보호해 둔 증거 덕분에 모든 것을 잃지는 않는다. 은호의 호루라기와 목소리 반전으로 기존 공통 결말에 합류한다.

## 4. 시간제한과 접근성 규칙

- 시작 전 ‘도전 시작’과 ‘천천히 하기’를 선택한다. 도중에도 무제한으로 전환 가능.
- 설명, 인물 대화, 기록 열람, 일시정지, 탭 숨김 중에는 타이머가 멈춘다.
- 프레임 수가 아니라 경과 시간으로 계산한다. 재개 첫 프레임에 숨겨져 있던 시간을 차감하지 않는다.
- 새로고침 뒤에는 마지막 구간과 남은 시간을 복원하고 정지 상태에서 사용자가 재개한다.
- 시간 종료와 성공이 겹쳐도 후속 대화·아이템 지급·완료 콜백은 한 번만 실행한다.
- 빠른 클리어는 친구 반응만 다르게 한다. 점수 때문에 사건 증거를 놓치거나 엔딩이 나빠지지 않는다.
- 체험 모드·본편 저장은 기존처럼 분리한다. 15초 오답 페널티는 다시 켜지 않는다.

## 5. 코드 구성과 저장

1편 room.js는 사물 윤곽·가방·조사 패턴을 참고하되 동작을 바꾸지 않는다. 장면별 조건이 많은 기존 모듈에 운동장 조건을 계속 추가하지 않는다.

- playground.js: 순수 상태 전이, 조사·아이템·진행 단계, 검증된 저장 복원.
- playground-view.js / playground.css: 배경, 윤곽, 열린 상태, 가방, 확대 조사, 입력 대안.
- activity-clock.js: 시작·정지·재개·시간 만료. 테스트에서 시각을 주입할 수 있게 한다.
- chapter2.js: 기존 장면 식별자를 최대한 유지하면서 탐색 구간과 사건 연결.
- weather-chapter.js: 기존 텍스트 활동의 본편 연결을 새 탐색으로 교체. 이전 완료 저장은 완료 상태로 안전하게 이관.
- app.js: mount/dispose, 저장 콜백, 공통 결말 연결만 담당.

운동장 상태는 flags의 독립 version 필드 포함 객체로 저장한다. phase, 조사 목록, 소지품, 선택 물건, 문/상자 상태, 미니게임 구간, 남은 시간, 완료 여부만 보관한다.
DOM 요소·타이머 ID는 저장하지 않는다. 알 수 없는 값과 누락 필드는 기본값으로 보정한다. 실제 플레이 순서에 없는 미래 단계 아이템은 복원 검증에서 거부한다.
이전 2편 저장의 fog/wind/schedule/photo 완료 여부는 각각 대응 완료 지점으로 변환하며 1편 flags는 건드리지 않는다.

## 6. 그림과 음향 범위

전용 운동장 전경, 창고 확대(닫힘/열림), 처마 아래 방송석, 저녁 사진 작업대가 필요하다.
기존 그림은 보존하고 신규 파일을 추가한다. 하나·정복 새 전신 캐릭터는 이 개편 필수 범위에서 제외하며 잘못된 인물 강조를 하지 않는다.
날아가는 순서표, 집게, 함의 덮개 등 실제 조작 물건은 별도 레이어로 분리해 윤곽과 상태가 맞게 한다.
거친 전자 비프 대신 종이·집게·바람·빗방울의 작은 효과음. 대사 읽기는 무음, 긴장 BGM은 사건 때만 전환한다.
새 외부 음원은 사용·배포 권한과 출처를 확인한 경우만 포함한다. 제공되지 않으면 기존 허용 음원을 재사용한다.

## 7. 완료 판정과 검증

- 본편에서 운동장 전경을 직접 조사하고 가방의 열쇠·집게·천·함을 실제 대상에 사용할 수 있다.
- 순서표를 회수하고 고정한 상태가 그림에 남는다. 열리지 않은 창고에서 도구를 얻거나 빈 함으로 완료할 수 없다.
- 두 타임어택 각각 성공·오조작·시간 만료·무제한 전환·탭 숨김·재개를 자동 테스트한다.
- 사진 심화는 사진과 근거 조합까지 검증하며 틀린 조합은 재시도 가능하다.
- 기존 24개 테스트와 새 상태·시간·저장 이관 테스트 전체를 실행한다.
- 실제 브라우저에서 한 경로를 2편 시작부터 공통 결말까지 진행하고, 다른 선택의 재합류도 확인한다.
- 390×844와 일반 데스크톱에서 클릭 영역·그림·대화·가방 겹침, 키보드/터치 대안을 확인한다.
- 실제 수업에서 검증하기 전에는 25~35분 또는 특정 난이도를 달성했다고 주장하지 않는다.

## 8. 이번 설계의 경계

현재 문서는 기존 초안의 개선 설계다. 구현·새 그림 생성·GitHub 업로드·배포 완료를 의미하지 않는다.
온라인 랭킹, 로그인, 실제 기상 데이터, 랜덤 엔딩, 3편 구현은 포함하지 않는다.
다음 단계는 사용자 설계 검토 후 테스트 우선 구현 계획 작성이다.
