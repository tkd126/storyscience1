# 2편 「안개 속에서 돌아온 대답」 구현 계획

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. 기존 사용자 변경을 보존하고 현재 작업에서 직접 구현한다.

**Goal:** 승인한 카툰 그림으로 운동장 조사 → 준비실 도구 사용 → 녹음 속 이름 발견까지 플레이 가능한 2편을 만든다.

**Architecture:** 기존 1편의 장면·인물·타이핑·저장 엔진을 유지한다. 새 2편은 이야기, 순수 탐색 상태, 탐색 화면을 분리하며 이전 2편의 중복 덮어쓰기 경로는 신규 플레이에서 사용하지 않는다.

**Tech Stack:** 정적 HTML/CSS/JavaScript, Node assert 테스트. 외부 설치·빌드 없음.

**Spec:** `docs/chapter2-story-redesign-v3.md`, `docs/chapter2-image-assets-v3.md`

## Global Constraints

- 하나의 정면 얼굴과 정체는 2편에서 공개하지 않는다.
- 전체 화면 배경, 배경 위 인물, 하단 대화창을 사용한다.
- 과학 정답은 사건의 단서 해석과 행동으로 연결한다. 무관한 암호나 시험 목록을 넣지 않는다.
- 시간제한·게임 오버 없음. 오답과 잘못된 도구는 재시도할 수 있다.
- 필수 조사 후 단서 연결 대사를 읽고 자동 이동한다. 교사 부르기·조사 완료 버튼 없음.
- 기존 그림·사용자 변경·1편 저장은 보존한다. GitHub 업로드와 배포는 이번 범위에서 제외한다.

## Review Focus

1. 조사 순서가 달라도 관측 기록을 확인하기 전 이슬이라고 단정하지 않는다.
2. 타이핑 중 클릭은 문장을 완성할 뿐 다음 대사까지 건너뛰지 않는다.
3. 대화가 닫힌 탐색에서 모든 필수 물체가 가려지지 않고 클릭된다.
4. 옛 2편 저장이 새 단계의 단서와 섞이지 않는다. 1편 진행은 유지한다.
5. 마지막 정답의 반응 대사를 읽기 전에 다음 장소로 넘어가지 않는다.

- [ ] 아래 테스트를 먼저 작성하고 실행해 모듈 부재 실패를 확인한다.

```js
const assert = require('node:assert/strict');
const fs = require('node:fs');
const layout = require('./chapter2-v3-layout');
for (const room of Object.values(layout)) {
  assert.ok(fs.existsSync(__dirname + '/' + room.art));
  for (const spot of room.spots) {
    assert.ok(spot.id && spot.label && spot.path);
    assert.ok(spot.bounds.every(Number.isFinite));
  }
}
```

- [ ] `layout`은 `{yard:{art,spots},prep:{art,spots}}`를 내보낸다. 각 spot은 `{id,label,path,bounds:[x,y,width,height]}`이며 원본 이미지 픽셀 기준이다. 실물을 보며 SVG path를 작성한다. 안개·하늘만 별도 면 강조를 쓴다.
- [ ] 배경과 SVG가 같은 viewBox로 크기 조정되도록 한다. 임의 사각형 fallback 금지. 카메라·천·백엽상·벤치·관목·골대·문·깃발·녹음기·테이프·선반·자·빗자루를 확인한다.
- [ ] Node 테스트와 1920×1080, 1280×720, 390×844 브라우저에서 윤곽·선택 가능 영역을 확인한다. 녹음기 확대 그림은 방 배경의 기기 형태·조명과 맞는지 확인 후 적용한다.

## 2. 운동장과 준비실 진행 규칙

Files: `prototype/chapter2-v3-state.js`, `prototype/chapter2-v3-state.test.js`.

Interface: `initial(saved)`와 `act(state,{type,target,value})`는 직렬화 가능한 새 상태를 반환한다. 상태는 `version:3, room, seen, answers, inventory, selected, dialogue, dialogueIndex, complete`를 가진다.

- [ ] 아래 행동 테스트를 먼저 작성한다.

```js
const assert = require('node:assert/strict');
const R = require('./chapter2-v3-state');
let s = R.initial();
s = R.act(s, {type:'answer',target:'dew',value:'이슬'});
assert.equal(s.answers.dew, undefined, '관찰 없이 답만 입력할 수 없음');
s = R.act(s, {type:'inspect',target:'weather-record'});
s = R.act(s, {type:'inspect',target:'leaves'});
s = R.act(s, {type:'answer',target:'dew',value:'비'});
assert.equal(s.answers.dew, undefined);
s = R.act(s, {type:'answer',target:'dew',value:' 이슬 '});
assert.equal(s.answers.dew, true);
assert.equal(R.initial(JSON.parse(JSON.stringify(s))).answers.dew, true);
assert.equal(s.room, 'yard', '정답 하나로 장소 이동하지 않음');
```

- [ ] 카메라 메모, 관측 기록, 잎·골대·하늘 조사와 답변을 저장한다. 마지막 답변 뒤 의미를 설명하는 대화가 끝나야 준비실로 이동한다.
- [ ] 준비실에서는 환기창 → 바람 방향 예상 → 선반 수색 → 긴 자 또는 빗자루 선택 → 종이 회수 → 집게 고정으로 연결한다. 문 손잡이의 끈 해제와 교사의 외부 열쇠 동작을 구분한다.
- [ ] 녹음은 메모 확인 → 테이프 획득 → 녹음기에 사용 → 되감기 → 재생 순서다. 단계 건너뛰기와 잘못된 도구가 완료를 만들지 않는 테스트를 추가한다.
- [ ] 조사 순서 역전, 두 도구 모두 성공, 오답 재시도, 매 행동 직후 직렬화·복원, 마지막 반응 대사 전 이동 금지를 테스트한다.

## 3. 전체 화면 탐색과 대사

Files: `prototype/chapter2-v3-view.js`, `prototype/chapter2-v3.css`, `prototype/chapter2-v3-view.test.js`.

Interface: `mount(panel,onDone,saved,onChange,playFoley)`는 정리 함수(dispose)를 반환한다. 상태는 2번 모듈만 변경한다.

- [ ] 타이핑의 첫 클릭은 완성, 둘째 클릭은 다음 대사라는 동작을 가짜 타이머로 검사한다. dispose 뒤 타이머와 입력 리스너가 남지 않아야 한다.
- [ ] 1편 화자 이름표·인물·하단 대화창을 재사용한다. 관찰 설명 뒤에는 대화창을 접고 물체를 다시 누를 수 있게 한다.
- [ ] 게임 화면 바깥 스크롤을 만들지 않는다. 세로 화면에서는 중요한 물체 접근을 보장하는 장면 이동을 제공하며 UI 자체는 고정한다.
- [ ] Enter/Space 및 배경 클릭 진행을 지원하되 입력란·도구 버튼 이벤트와 중복 실행하지 않는다. 선택 물건은 실제 대상에 사용한다.
- [ ] 종이 이동은 별도 레이어로 표시한다. 동작 줄이기 설정에서는 최종 위치를 즉시 보여 준다. 기본 배경에 남은 종이와 중복되지 않게 한다.
