# 2편 촬영 기록 추적 구현 계획

**Goal:** 승인된 빈 운동장 → 목소리 → 안개 관찰 → 첫 대면 → 촬영 기록 회수 → 사진 증거 흐름을 구현한다.
**Architecture:** 기존 정적 JS 상태·RoomScene을 유지한다. 저장용 장면 ID는 보존하고 장면 연결을 변경한다. 첫 만남에는 관찰 선행 조건, 후반에는 대상별 행동을 제공한다.
**Tech Stack:** HTML/CSS/JavaScript, Node 테스트.
**Spec:** 2026-09-18 사용자 승인 대화. 체육대회 삭제, 하나 지연 등장, 1편 화면, 가방 대신 사물 조사.

## 실행 순서
- [ ] hana-search.js: 렌즈/공기 관찰 이전 approach는 발견하지 않는다. 천→렌즈→골대 관찰 후 접근한다. 저장 복원 검증.
- [ ] hana-search-view.js: 천·렌즈 행동과 다음 조사 안내를 하단 대사에 연결. 발견 전 하나 이미지 없음 검증.
- [ ] playground-view.js: 가방 대신 대상의 가능한 행동 제공. 교사 미니어처 삭제하고 화면 안 교사 버튼 제공. 완료 버튼 및 키보드 접근 보장.
- [ ] immersive-room.css: 첫 만남과 후반 모두 같은 대화 크기, 이름표, 버튼 영역. 좁은 화면에서도 UI는 스크롤 배경과 분리.
- [ ] chapter2.js: 체육대회 대신 교사가 촬영 기록을 함께 확인하는 사건으로 재작성. 선택은 두 대사 이상 후 합류. 날씨와 사진 시간 정합성 검사.
- [ ] evidence-task.js/playground.js: 바통·경기 증거를 촬영 소품 전달로 교체. 기존 삽화를 촬영 장면이라고 오인시키지 않도록 교체 또는 명시적 관찰 자료로 제시.
- [ ] 테스트: 발견 선행 조건, 대상별 행동, 무가방 완료, 모든 장면 연결, 저장 복원, 전체 Node 테스트.
- [ ] 브라우저: 1편 회귀, 2편 연속 진행, 잘못된 시도와 재시도, 1280×720 및 좁은 화면 잘림 확인. 배포는 별도 요청 전 보류.

기존 사용자 변경은 보존한다. 테스트의 기존 체육대회 기대값은 새 이야기의 구체적 근거로 교체한다. 테스트 통과를 실제 학생 학습효과 검증으로 소개하지 않는다.
