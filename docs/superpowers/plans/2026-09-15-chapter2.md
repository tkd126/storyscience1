# 2편 날씨와 우리 생활 Implementation Plan

**Goal:** 승인된 ‘운동회에 없는 아이’를 1편 직후부터 필름 도난까지 플레이 가능하게 연결한다.
**Architecture:** Chapter2가 장면 데이터를 제공하고 WeatherChapter가 독립 활동 상태/채점/UI를 담당한다. app.js는 기존 저장 flags 및 장면 엔진으로 연결한다.
**Tech Stack:** 정적 HTML/CSS/JS, Node assert, 기존 이미지.
**Spec:** 사용자 승인 구성(2026-09-15), 기획 인수인계 9장 및 2단원 목록.

## 제약
- 빌드/설치 없이 실행. 기존 1편 저장 유지. 오답 후 즉시 재시도.
- 이름·목소리로 잠시 기억을 붙잡고, 사진은 추가 증거일 뿐 만능 해결이 아니다.
- 겨울 행사는 짧은 학급 행사. 교사가 날씨와 바닥 상태를 확인하고 중단 결정.
- 표의 기상 수치는 게임용 가상 기록. 실제 안전 기준 아님.
- 새 인물 삽화는 이번에 생성하지 않는다. 하나·정복 발화에는 타인 캐릭터를 화자로 강조하지 않는다.

## 실행 순서
- [ ] `chapter2.test.js`: 장면 전 경로 공통 결말 도달, 4개 활동 포함, 날짜, 오답 보존·순서·저장 복원 테스트를 먼저 작성하고 실패 확인.
- [ ] `weather-chapter.js`: `initial(kind,saved)`, `act(state,action)`, `mount(host,kind,done,saved,onSave)` 구현. fog(관찰3종/응결), wind(지도 관찰/방향/위치), schedule(관측표/계획/근거), photo(기록3개/시각 입력/배치) 순서.
- [ ] `chapter2.js`: `build()`로 12월28일 만남, 29일 행사·기억 변화, 4개 활동, 고백·촬영, 밤 필름도난 장면. 선택은 두 반응을 거쳐 공통 장면 합류.
- [ ] app/index 연결: 1편 끝 버튼→2편, 독립 미리보기, 날짜/배경/BGM, 활동 상태 flags 저장, 2편 종료 화면.
- [ ] `chapter2.css`: 종이 패널/관측표/지도/이름표; 좁은 화면 단일열, 모든 입력 라벨.
- [ ] 전체 Node 테스트와 브라우저 직접 조작(오답→재시도, 활동 완료→스토리) 검증. CONTINUE_HERE에 실제 완료 범위 기록. 배포는 별도 요청 시.
