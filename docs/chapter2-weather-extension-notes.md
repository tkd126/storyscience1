# 2편 후반 확장 · 2026-09-22

자료실 사진의 시간 모순을 확인한 뒤, 테이프 뒷면 글씨와 관측실의 기록을 비교한다. 정답 자체가 문을 여는 것이 아니라 기록의 분류와 목적지를 알아내는 근거가 된다. 편집실에서는 낮/밤 관측 기록으로 틀린 표찰을 가려내고 마지막 목소리를 찾는다. 하나의 정체는 공개하지 않는다.

## 구현과 범위

- 필수 7개: 저기압으로 모이는 바람, 고기압의 보통 날씨, 저기압의 보통 날씨, 같은 부피·기압의 공기 무게, 기압차 단순 모형 방향, 해풍, 육풍.
- 선택 3개: 곡풍, 병합설, 빙정설. 오답은 힌트와 재시도. 선택 활동 없이도 결말 합류.
- 무게는 용기 무게를 뺀 공기 비교 기록이며 가열 조작 없음. 밀폐된 공기를 데우면 질량이 줄어든다는 뜻이 아님.
- 고/저기압 날씨는 일반적인 경향. 실제 일기도의 바람을 무조건 등압선에 수직이라고 설명하지 않으며 기압차만 고려하는 단순 모형임을 표시.
- 해륙풍도 관측 기록과 햇빛을 함께 사용하며 바람 하나만으로 촬영 시각을 단정하지 않음.
