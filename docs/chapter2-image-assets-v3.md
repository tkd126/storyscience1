## 구현에서 지킬 것

실제 파일은 `prototype/assets/chapter2-v3/`의 `playground.png`, `prep-room.png`, `dew.png`, `recorder.png`에 보존했다. 기존 배경은 덮어쓰지 않았다. 이 파일 복사는 게임 화면 교체를 의미하지 않는다.

- 하늘·안개는 실체가 있는 물건처럼 임의 외곽선을 그리지 않는다. 부드러운 강조와 이름으로 반응한다.
- 고정 물체는 실제 그림에 맞춘 경로나 마스크를 사용한다. 가상의 사각형 대체 테두리를 금지한다.
- 종이 이동, 녹음기 테이프 삽입, 문 열림은 별도의 상태 그림 또는 분리된 오브젝트가 필요하다. 한 배경 그림만으로 상태 변화까지 완성되었다고 보지 않는다.
- 풀잎 관찰은 물 흔적 오해를 해소하고, 안개 관찰은 시야 제한을 설명한다. 구름의 존재만으로 비나 위험을 단정하지 않는다.
- 하나는 배경에 얼굴을 그려 넣지 않는다. 후속 실루엣은 별도 레이어로 넣어 공개 시점을 제어한다.
- 생성 그림의 형태·여백·물체 간 간격을 검수한 뒤 좌표를 확정한다. 작은 화면에서도 물건이 대화창에 가리지 않는지 확인한다.
