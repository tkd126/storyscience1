# 1999년 12월 31일, 우리 학교가 사라진다 — 연습판

5학년 과학 단원 마무리용 미연시형 게임의 프롤로그와 1편 첫 실험 시작품입니다.

## 이번에 추가한 구간

- 프롤로그: 사라지는 이름 → 은호의 기억 이상 → 삐삐 메시지 → 방송실로 간다.
- 1편 미리보기: 방송실 앞에서 행사 준비를 돕게 되고 고운 모래·작은 자갈·큰 자갈을 직접 분리합니다.
- 실험 전 ‘혼합물’과 ‘알갱이 크기’를 직접 입력해 이야기 속 질문에 답합니다. 오답이면 인물이 힌트를 주고 다시 답할 수 있습니다.
- 촘촘한 체·중간 체·성긴 체 중 하나를 고르고, 통과할 재료를 예상한 다음 4번 흔들어 결과를 관찰합니다.
- 한 번에 끝나지 않습니다. 먼저 분리된 재료를 알맞은 통에 보관하고, 남은 혼합물을 다른 체로 다시 나눠 세 재료를 모두 찾아야 합니다.
- 중간 체와 성긴 체 중 어느 것을 먼저 사용해도 해결할 수 있습니다. 틀린 체도 재선택 가능하며 시간제한이나 실패 엔딩은 없습니다.
- 마지막에는 체 눈과 알갱이 크기를 비교해 분리 원리를 다시 설명합니다.
- 첫 실험 후 하나의 그림과 방송 목소리를 확인하는 공통 장면으로 합류합니다.
- 실험 중 새로고침하면 해당 실험 처음부터 다시 시작합니다. 이야기 진행과 완료 상태는 저장합니다.
- 물·기름과 소금·모래 실험은 아직 포함하지 않았습니다. 이 버전은 1단원 전체 완성본이 아닙니다.
- `sieve.js`: 실험 규칙, Canvas 표시와 포인터/버튼 조작.
- `sieve.test.js`, `sieve-advanced.test.js`, `chapter1.test.js`: 다단계 분리·재료 보존·재시도 규칙과 장면 연결 테스트.

기존 배경을 재사용하는 연습판이며 방송실 전용 배경은 후속 작업입니다.

## 실행 방법

1. `index.html`을 더블 클릭합니다.
2. 웹 브라우저가 열리면 주인공 이름을 입력하고 **테이프 재생하기**를 누릅니다.
3. 대화 상자를 누르면 이야기가 진행됩니다.

별도 설치나 인터넷 연결이 필요하지 않습니다. Chrome, Edge 등의 최신 브라우저를 권장합니다.

## 현재 들어 있는 기능

- 이름을 입력하면 대사에 자동으로 반영
- 선택지에 따라 은호의 신뢰와 의심 수치 변화
- 어떤 선택지를 골라도 아래 대화창에 짧은 반응이 나온 뒤 같은 핵심 스토리로 합류
- 중요 선택 3곳은 각각 다른 짧은 장면을 한 번 거친 뒤 다시 본줄기로 합류
- 비디오테이프·시간 이동·출석부 연출
- 대화 기록, 소리 끄기/켜기, 처음부터 다시 하기
- 브라우저 자동 저장과 이어하기
- 컴퓨터·태블릿·휴대전화 화면 대응

## 수정할 때 보면 되는 파일

- `app.js`: 스토리, 대사, 선택지, 선택 결과
- `styles.css`: 색상, 글자 크기, 배치, 연출
- `index.html`: 시작 화면과 게임 화면의 기본 구조
- `assets/school-twilight-v3.png`: 어두운 학교 시작 화면
- `assets/science-room-night-v3.png`: 현재의 과학준비실
- `assets/classroom-vhs-v3.png`: 비디오테이프 속 교실
- `assets/classroom-1999-dusk-v3.png`: 1999년 겨울 교실
- `assets/characters/`: 태오·소미·은호의 감정 5종과 1999년 남자 담임의 감정 3종
- `character-layout.js`: 인물 수와 화자에 따른 미연시형 위치·크기 배치
- `character-moods.js`: 장면에 알맞은 표정과 동작 선택

## 코덱스에서 이어서 만들 때 사용할 요청문

```text
prototype 폴더의 연습 게임을 기반으로 5학년 과학 단원 마무리 게임을 이어서 만들어 줘.
기존 스토리와 분위기는 유지하고, 스토리 속 행동이나 위기 해결 과정에 5학년 과학 개념을 자연스럽게 사용해 줘.
선택 결과와 등장인물 관계가 다음 단원으로 이어지게 하고, 먼저 추가할 단원의 스토리와 게임 규칙을 제안한 뒤 구현해 줘.
```

## 연습판 범위

이 버전은 프롤로그와 첫 단원의 **혼합물 직접 입력 문제 및 다단계 체 분리 실험**까지 구현한 시작품입니다. 아직 첫 단원 전체 완성본은 아니며, 다음 버전에서는 나머지 개념을 `단서 발견 → 예상 → 행동 선택 → 결과 → 설명` 구조로 확장하면 됩니다.

과학 문제도 같은 원칙을 사용합니다. 정답은 단서나 관계 점수를 더 얻고, 오답은 작은 실수·웃긴 사건·추가 힌트 중 하나를 겪습니다. 다만 각 단원의 마지막 핵심 사건과 결말은 같게 유지합니다. 즉, `짧은 분기 → 재합류 → 공통 결말`의 다이아몬드형 구조입니다.
