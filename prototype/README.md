# 1999년 12월 31일, 우리 학교가 사라진다 — 연습판

5학년 과학 단원 마무리용 미연시형 게임의 프롤로그와 1편 첫 실험 시작품입니다.

## 이번에 추가한 구간

- 2026-09-11: 1편 촬영 설정은 교사가 촬영하고 하나·은호가 과학 수업을 소개하는 학교생활 소개 영상입니다. 실험 결과와 원고를 비교해 행선지를 추적하며, 이름을 기록하고 읽어 기억을 잠시 붙잡습니다. 1편 끝은 즉시 운동장으로 향하고 실제 후속 플레이는 제작 중입니다.

- 기본 화면도 브라우저를 채웁니다. 전체화면 버튼으로 확장하면 인물·대화·선택지도 화면에 맞춰 커집니다. `cartoon-ui.css`가 종이색 UI와 반응형 배치를 담당합니다.
- 이야기 선택 18개는 첫 반응 뒤 다른 인물의 대화를 한 번 더 거칩니다. `choice-dialogue.js`에서 수정합니다. `foley.js`는 녹음이 아닌 짧은 질감 합성음이며 음소거 가능합니다.

- 오전 교실 아침 배경과 방송실 전용 삽화를 추가했다. 방송실에서는 그림 속 창문·접시·서랍·비디오·게시판·장비·문을 직접 누른다.
- 소지품을 선택해 서랍과 비디오에 사용하는 탐색, 세 실험의 원고 복원, 환경 방송 장치 선택과 이유 설명, 테이프 단서를 통한 문 열기가 추가됐다. 기존 231 상자는 제거했다.
- `room.js`와 `room.test.js`가 탐색 진행·소지품·선행 조건·저장을 담당한다. 시작 화면의 새 탐색 체험은 본편 저장을 덮어쓰지 않는다.

- 각 에피소드 완료 화면에는 의미 없는 관계 숫자 대신 플레이 선택에 따라 달라지는 칭호 하나만 표시합니다.
- 장식용 재료 배너 없이 목표·이유·성공 모습을 먼저 보여 줍니다. 체 선택지는 철망과 손잡이가 있는 금속 체로 보이며, 재료 비교 카드에는 모래알 무리·작은 자갈 여러 개·큰 자갈 한 개가 같은 관찰 범위 안에 표시됩니다. Canvas의 체를 흔들면 체가 기울고 작은 입자가 받침으로 떨어진 뒤 실제 분리 결과가 나타납니다.

- 프롤로그의 현재 시각 오후 4시 44분과 영상 속 1999년 12월 31일 밤을 화면에서 명확히 구분했습니다. 시간 이동 뒤에는 첫 수업과 수업 종료 종을 거쳐 쉬는 시간이 시작됩니다.
- 과학 문제 또는 실험 방법을 틀리면 친구의 설명을 읽는 15초 동안 다른 답과 다음 진행 버튼이 잠깁니다. 이야기의 취향 선택에는 정답·오답이나 대기 시간을 적용하지 않습니다.

- 하나의 작업 메모를 발견하고 당번 일을 이어받습니다. 실험 후 용어·근거·방법 수정·새 상황 적용·서술을 포함한 6단계 인수인계 메모를 작성합니다. 서술형은 실제 실험 결과와 비교해 스스로 고치며, 자동 정오 판정을 하지 않습니다.

- 프롤로그: 사라지는 이름 → 은호의 기억 이상 → 삐삐 메시지 → 방송실로 간다.
- 1편 미리보기: 방송실 앞에서 행사 준비를 돕게 되고 고운 모래·작은 자갈·큰 자갈을 직접 분리합니다.
- 실험과 재료 배치를 마친 뒤 ‘혼합물’과 ‘알갱이 크기’를 직접 입력해 메모를 남깁니다. 오답이면 관찰을 유도하는 힌트를 단계별로 볼 수 있습니다.
- 촘촘한 체·중간 체·성긴 체 중 하나를 고르고 바로 4번 흔들어 결과를 관찰합니다. 별도의 예상 답변은 요구하지 않습니다.
- 한 번에 끝나지 않습니다. 먼저 분리된 재료를 알맞은 통에 보관하고, 남은 혼합물을 다른 체로 다시 나눠 세 재료를 모두 찾아야 합니다.
- 현재 학생 화면은 큰 자갈을 먼저 분리한 뒤 남은 모래·작은 자갈을 나누는 순서입니다. 틀린 체도 재선택 가능하며 시간제한이나 실패 엔딩은 없습니다.
- 마지막에는 체 눈과 알갱이 크기를 비교해 분리 원리를 다시 설명합니다.
- 첫 실험 후 하나의 그림과 방송 목소리를 확인하는 공통 장면으로 합류합니다.
- 실험 중 새로고침하면 해당 실험 처음부터 다시 시작합니다. 이야기 진행과 완료 상태는 저장합니다.
- 물·기름은 층 관찰과 용기 교체, 소금·모래는 녹이기·거르기·교사 가열 관찰로 분리합니다. `liquid-labs.js`가 담당하며 `liquid-labs.test.js`로 검사합니다. 세 실험 뒤 이름을 보관하는 공통 결말로 이어집니다. 교과서 전체 성취기준 대조는 남아 있습니다.
- 물·기름은 빈 분별깔때기에 물과 식용유를 직접 차례로 넣어 층이 생기는 모습을 확인합니다. 소금·모래 실험 전에는 방송실 작업대의 세 물건을 눌러 앞선 개념 문제를 풀고 세 자리 번호로 소품 보관함을 엽니다. 물을 넣은 뒤에는 비커의 물층과 바닥 모래가 따로 보입니다.
- `sieve.js`: 실험 규칙, Canvas 표시와 포인터/버튼 조작.
- `sieve.test.js`, `sieve-advanced.test.js`, `chapter1.test.js`: 다단계 분리·재료 보존·재시도 규칙과 장면 연결 테스트.

기존 배경을 재사용하는 연습판이며 방송실 전용 배경은 후속 작업입니다.

## 실행 방법

1. `index.html`을 더블 클릭합니다.
2. 웹 브라우저가 열리면 주인공 이름을 입력하고 **테이프 재생하기**를 누릅니다.
3. 대화 상자를 누르면 이야기가 진행됩니다.

별도 설치나 인터넷 연결이 필요하지 않습니다. Chrome, Edge 등의 최신 브라우저를 권장합니다.

## 현재 들어 있는 기능

- 이름을 입력하면 대사에 자동으로 반영
- 선택지에 따라 은호의 신뢰와 의심 수치 변화
- 어떤 선택지를 골라도 아래 대화창에 짧은 반응이 나온 뒤 같은 핵심 스토리로 합류
- 중요 선택 3곳은 각각 다른 짧은 장면을 한 번 거친 뒤 다시 본줄기로 합류
- 비디오테이프·시간 이동·출석부 연출
- 대화 기록, 소리 끄기/켜기, 처음부터 다시 하기
- 브라우저 자동 저장과 이어하기
- 컴퓨터·태블릿·휴대전화 화면 대응

## 코덱스에서 이어서 만들 때 사용할 요청문

```text
prototype 폴더의 연습 게임을 기반으로 5학년 과학 단원 마무리 게임을 이어서 만들어 줘.
기존 스토리와 분위기는 유지하고, 스토리 속 행동이나 위기 해결 과정에 5학년 과학 개념을 자연스럽게 사용해 줘.
선택 결과와 등장인물 관계가 다음 단원으로 이어지게 하고, 먼저 추가할 단원의 스토리와 게임 규칙을 제안한 뒤 구현해 줘.
```

## 연습판 범위

이 버전은 프롤로그와 첫 단원의 **혼합물 직접 입력 문제 및 다단계 체 분리 실험**까지 구현한 시작품입니다. 아직 첫 단원 전체 완성본은 아니며, 다음 버전에서는 나머지 개념을 `단서 발견 → 예상 → 행동 선택 → 결과 → 설명` 구조로 확장하면 됩니다.

과학 문제도 같은 원칙을 사용합니다. 정답은 단서나 관계 점수를 더 얻고, 오답은 작은 실수·웃긴 사건·추가 힌트 중 하나를 겪습니다. 다만 각 단원의 마지막 핵심 사건과 결말은 같게 유지합니다. 즉, `짧은 분기 → 재합류 → 공통 결말`의 다이아몬드형 구조입니다.
